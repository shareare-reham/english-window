# 🌐 English Window (English জানালা)

> An interactive, lesson-based web application designed to help Bengali speakers expand their English vocabulary through structured levels, audio pronunciation guide, detailed meanings, and synonyms.

---

## 🔗 Live Demo & Repository

- 🚀 **Live Site:** [https://shareare-reham.github.io/english-window/](https://shareare-reham.github.io/english-window/)
- 📦 **GitHub Repository:** [https://github.com/shareare-reham/english-window](https://github.com/shareare-reham/english-window)

---

## ✨ Features

- **📚 Lesson-Based Learning:** Interactive level buttons fetched dynamically from external APIs to browse vocabulary lesson by lesson.
- **🔍 Real-Time Word Search:** Search for specific words across all lessons with instant filtering and friendly empty state indicators.
- **🔊 Word Details & Pronunciation:** View English words alongside their Bengali meanings, phonetic pronunciations, and example sentences in a clean modal UI.
- **🏷️ Synonyms Support:** Modal display highlights synonyms for deep vocabulary building.
- **⏳ Loading Spinner Indicator:** Smooth loading states for fetching asynchronous API data.
- **📱 Fully Responsive Design:** Clean layout built for Desktop, Tablet, and Mobile devices using Tailwind CSS and DaisyUI components.
- **❓ Interactive FAQ Section:** Collapsible accordion UI answering common user queries.

---

## 🛠️ Tech Stack & Dependencies

- **HTML5** & **CSS3**
- **JavaScript (ES6+)** — Fetch API, DOM Manipulation, Async Handling
- **Tailwind CSS v4** — Utility-first styling
- **DaisyUI v5** — UI component library (modals, accordions, buttons, navigation)
- **FontAwesome 7** — Modern UI icons
- **Google Fonts** — *Poppins* & *Hind Siliguri* (for English & Bengali typography)
